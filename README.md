# Sistema de Administración de Empleados

Proyecto final del Taller API con Node.js.

## Tecnologías

- Node.js
- Express.js
- PostgreSQL
- JWT
- Docker Compose
- Bootstrap

## Ejecutar el proyecto

```bash
docker compose up -d --build
```

Abrir en el navegador:

http://localhost:3000/login.html
